## 第二步：测试用例 1 - 正常程序片段（成功示例）

### 测试目标
验证正常程序能够被正确解析，并输出完整语法树。

### 运行方式

#### 方式 A：通过文件输入

1. 在 `syntax_analyzer` 目录新建文件 `test1_success.txt`，内容为：
   ```
   int x = 1;
   while (x < 10) {
       x = x + 1;
   }
   ```

2. 运行分析器
   ```powershell
   .\syntax.exe test1_success.txt
   ```

#### 方式 B：通过管道输入（文本会换行显示）

```powershell
@'
int x = 1;
while (x < 10) {
    x = x + 1;
}
'@ | .\syntax.exe
```

### 预期输出

```
Syntax analysis succeeded.
Syntax tree:
Program
  TranslationUnit
    Declaration
      Type:int
      InitDeclaratorList
        Declarator:x
        InitDeclarator
          Identifier:x
          Add
            ...
    WhileStatement
      LessThan
        Identifier:x
        IntConst:10
      CompoundStatement
        StatementList
          ExpressionStatement
            Assign
              Identifier:x
              Add
                Identifier:x
                IntConst:1
```

### 测试验证要点

- [ ] 输出"Syntax analysis succeeded."
- [ ] 语法树根节点为"Program"
- [ ] 能看到"WhileStatement"
- [ ] 能看到"Declaration"和"Assign"
- [ ] 整棵树层次清晰，没有错误信息

## 第六步：快速验证脚本

如果要快速测试所有用例，可以创建 PowerShell 脚本 `test_all.ps1`：

```powershell
# 测试用例集合
$tests = @(
    @{name = "test1_success"; input = @"
int x = 1;
while (x < 10) {
    x = x + 1;
}
"@ },
    @{name = "test2_error_decl"; input = "int x = ;" },
    @{name = "test3_error_semicolon"; input = "int x = 1" },
    @{name = "test4_complex_error"; input = @"
int x = ;
while (y < 10) {
    y = y + 1
}
"@ }
)

# 运行测试
foreach ($test in $tests) {
    Write-Host "========== Testing: $($test.name) ==========" -ForegroundColor Yellow
    $test.input | .\syntax.exe
    Write-Host ""
}
```

保存后运行：
```powershell
.\test_all.ps1
```

## 常见问题排查

### Q1：运行 `syntax.exe` 时提示"无法将...项识别为 cmdlet"

**解决方案：**
- 确保你在 `syntax_analyzer` 目录下
- 使用完整路径：`.\syntax.exe test1_success.txt`
- 或者用 PowerShell 的 `&` 操作符：`& ".\syntax.exe" "test1_success.txt"`

### Q2：输入管道时显示"Enter source text"

**解决方案：**
- 确保已经通过管道传入内容，如：`"int x = 1;" | .\syntax.exe`
- 或者直接用文件：`.\syntax.exe test1_success.txt`

### Q3：文件输入提示"lexical error"或乱码

**解决方案：**
- 检查文件编码是否是 UTF-8（带或不带 BOM 都可以）
- 避免在文件中混用 Windows 的 CRLF 和 Unix 的 LF 换行符

### Q4：语法树输出不完整或没有输出

**解决方案：**
- 确认输出"Syntax analysis succeeded."
- 如果只输出"Syntax analysis failed."，说明有语法错误
- 查看错误消息定位问题
